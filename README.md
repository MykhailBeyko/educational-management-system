# Система управління навчальним процесом

Навчальний проєкт на C# (.NET 10). Консольна програма для роботи зі студентами, викладачами, предметами та оцінками.

Реалізовано додавання і редагування оцінок, різні шкали оцінювання, підрахунок середнього бала, рейтинги та звіти. Є кафедри, групи й фільтрація студентів.

На 5–6 етапах додано SQLite через Entity Framework Core, вхід через [Security API](https://github.com/negativchik09/Security) та окремі меню для студента, викладача, завідувача й адміністратора.

## Запуск

Потрібні .NET SDK 10, ASP.NET Core Runtime 8 та Git.

Спочатку з папки проєкту запустити API:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Start-Security.ps1
```

Скрипт сам завантажить Security і запустить його. Swagger доступний за адресою http://localhost:5252/swagger/index.html.

Потім в іншому терміналі запустити програму:

```powershell
dotnet run --project systemforstudent.csproj
```

Вхід адміністратора: `admin`, пароль `Admin_password1`.

Через меню адміністратора можна створювати акаунти. Для ролей `Student`, `Teacher` та `DepartmentHead` треба вказати ID відповідного студента, викладача або кафедри. Для `Admin` — 0.

База `university.db` створюється автоматично. Якщо при першому запуску є `data.json`, дані переносяться з нього. Збережені звіти знаходяться в папці `reports`.
